# Датасет модели сходства `pairs_v1.npz`

Пары «объект картины — трек» с меткой «тот же объект эталона». Построен 22.11.2026
`tools/make_dataset.py` из прогонов симулятора с эталоном (`tools/dump_runs.py`).
Прогоны детерминированы (seed) и воспроизводятся командой ниже; сами прогоны
(`data/raw/*.pkl`) в репозиторий не входят.

```
python tools/dump_runs.py scenarios/base.toml scenarios/ai/{dense,hard,nav15,confusion}.toml --seeds 1-8
python tools/make_dataset.py data/raw/{base,dense,hard,nav15,confusion}_s[1-8].pkl --out data/pairs_v1.npz
```

| Сценарий | Пар | «Тот же объект» | Что проверяет |
|---|---|---|---|
| base | 2360 | 2343 | основной сценарий журнала (60 одиночных объектов) |
| dense | 6356 | 4127 | 120 объектов группами по 4 (круг 60 м, не ближе 25 м) |
| hard | 6862 | 4149 | dense + навигация σ 10 м + путаница классов 0,2 |
| nav15 | 2381 | 2345 | навигация σ 15 м |
| confusion | 2353 | 2344 | путаница классов 0,3 |
| **всего** | **20 312** | **15 308** | 15 874 решений «трек — кандидаты», 40 прогонов |

Разбиение — по прогонам: обучение seed 1–6, проверка (подбор модели и порога) seed 7–8.
Контрольная выборка (цикл 4) — seed 11–20, в датасет не входит.

Поля: `X` (пары × 18 признаков, `features` — имена, описание — `similarity.FEATURES`),
`y` (1 — тот же объект эталона), `group` (номер решения), `run`, `seed`, `scenario`,
`runs` (имена прогонов).

Как получены пары: повтор цикла ассоциации `fusion.compute_picture` по итоговому хранилищу
прогона; решения принимает учитель по эталону (трек присоединяется к кандидату того же
объекта эталона, иначе открывает новый объект), поэтому объекты учителя чистые. Для
каждого трека записываются все кандидаты в соседних ячейках, кроме запрещённых правилом
«один борт одновременно» и дальше d² = 64. Метка трека — объект эталона, давший большинство
его отметок (`node.truth_of`).

Ограничения: только данные симулятора (модель датчика, навигации, канала цикла 2);
признаки внешнего вида (эмбеддинг) пока не моделируются. Дообучение на данных лётных
испытаний — 2027 г. (Р-ИИ-3).
