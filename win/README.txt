Симулятор «Согласие» — переносимая версия для Windows
Лот 1, ФТ № 1 «Согласование информационной картины между БВС»
Версия модели {version}, коммит {commit}, сборка {built}

ЗАПУСК (установка и интернет не нужны)
1. Распакуйте архив целиком в любую папку (например, на Рабочий стол).
   Запускать прямо из окна архива нельзя — сначала «Извлечь всё».
2. Дважды щёлкните start.bat.
   Откроется чёрное окно сервера и страница симулятора в браузере.
   Если Windows покажет «Система Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (файлы не подписаны нами;
   python.exe — официальный, подписан Python Software Foundation).
3. Если браузер не открылся сам — скопируйте адрес из чёрного окна
   (http://127.0.0.1:8765/ или близкий) в Microsoft Edge, Chrome или Firefox.
4. Первая загрузка страницы — 5–15 с (загружается среда расчёта, 16 МБ, с этого компьютера).
5. Работа закончена — закройте чёрное окно.

ТРЕБОВАНИЯ
Windows 10 или 11, 64 бит; браузер Edge, Chrome или Firefox (версии 2024 г. и новее);
4 ГБ ОЗУ, 100 МБ на диске. Права администратора не нужны.

САМОПРОВЕРКА
Подробно — в инструкции по запуску (в составе заявки). Кратко:
выберите сценарий С1 → «Запустить» → через 10–20 с появятся показатели ФТ № 1 с отметками ✓/✗.
Измените исходные данные (например, потери сообщений 5 → 20 %) → «Запустить» → показатели изменятся.

СОСТАВ
start.bat     — запуск
serve.py      — локальный веб-сервер (только для этого компьютера, адрес 127.0.0.1)
python\       — встраиваемый Python {python} для Windows (python.org), используется только как сервер
web\          — страница симулятора; расчёт выполняется в браузере (Pyodide — Python в WebAssembly)
data\         — история изменений, журнал циклов разработки, исходные данные (при наличии)
SHA256SUMS    — контрольные суммы файлов

ЕСЛИ НЕ РАБОТАЕТ
• «Не удаётся найти python.exe» — архив распакован не целиком.
• Страница пустая или «Загрузка среды…» дольше минуты — обновите страницу (F5);
  проверьте, что браузер не Internet Explorer.
• Порт занят — сервер сам выберет другой и покажет адрес в чёрном окне.
• Без Windows: в папке с архивом выполните  python3 serve.py  (нужен Python 3.8+).
