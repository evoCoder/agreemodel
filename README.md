# agreemodel

Симулятор технологии **согласования информационной картины между БВС** (ФТ № 1, лот 1
«Технологии группового взаимодействия беспилотных воздушных судов, принятия решений и
комплексных систем управления беспилотными воздушными судами»).

Каждый борт роя ведёт у себя общую картину — состав группы, взаимное положение, объекты
интереса — без центра и при разрывах связи; после восстановления связи картины
согласуются без потери накопленного и сходятся к одинаковому состоянию.

## Принцип

1. **Реплицируемое хранилище** (`store.py`): каждая запись принадлежит одному борту-
   источнику, писать её может только он — конфликтов записи нет. Слияние копий —
   покомпонентный максимум по номеру версии (CRDT): копии сходятся при любом порядке,
   повторах и потерях сообщений. Синхронизация — по векторам версий, передаётся только
   недостающее.
2. **Картина = f(хранилище)** (`fusion.py`): треки разных бортов объединяются в
   каноническом порядке с ковариационным пересечением (без ложного сужения ошибки при
   коррелированных данных), идентификаторы объектов — хеш, одинаковый на всех бортах.
   Одинаковое содержимое хранилища даёт одинаковую картину.
3. **Анти-энтропия** (`node.py`): борты обмениваются векторами версий и вытягивают
   недостающее по каждому источнику у одного соседа.

## Запуск

Нужен Python 3.11+ и numpy.

```bash
pip install -e .[dev]
python -m agreemodel run scenarios/base.toml --out runs/base
python -m agreemodel run scenarios/base.toml --set net.loss=0.2 --set run.seed=11
python -m pytest
```

Итоги прогона — `summary.json` (показатели ФТ № 1), временной ряд — `series.csv`,
параметры — `scenario.json`.

## Веб-версия

Тот же код модели исполняется в браузере (Pyodide — Python в WebAssembly — и numpy);
страница статическая, сервер расчётов не нужен, во внешние сети во время работы не
обращается.

```bash
python tools/build_web.py                    # → dist/web (≈ 16 МБ)
python -m http.server 8765 -d dist/web       # открыть http://127.0.0.1:8765/
```

| Файл | Назначение |
|---|---|
| `web/index.html`, `app.js`, `style.css` | интерфейс: сценарии самопроверки, исходные данные, показатели ФТ, карта, графики, выгрузка |
| `web/presets.js` | сценарии самопроверки С1–С6 (изменения относительно `scenarios/base.toml`) |
| `web/worker.js` | расчёт в фоновом потоке браузера |
| `web/py/soglasie_web.py` | связка модели со страницей: сценарий из параметров, кадры для карты, ход выполнения |
| `web/vendor.json` | закреплённая версия Pyodide и numpy с контрольными суммами |
| `tools/build_web.py` | сборка; `version.json` — версия, коммит, дата; `SHA256SUMS` |
| `tests/test_web.py`, `tests/web/e2e.mjs` | проверки связки и собранной страницы в браузере |

## Состав

| Модуль | Назначение |
|---|---|
| `hlc.py` | гибридные логические часы (нет внешнего опорного времени) |
| `store.py` | реплицируемое хранилище, векторы версий, дельты |
| `fusion.py` | детерминированная общая картина: ассоциация, CI, неоднозначности |
| `node.py` | бортовой узел: локальное сопровождение, запись, обмен, пересчёт картины |
| `world.py`, `sensors.py` | эталон истины: рой, маршрут, объекты; датчик и навигация без ГНСС |
| `net.py` | сеть роя: разделение на подгруппы, потери, задержка, полоса |
| `sim.py`, `cli.py` | прогон сценария и показатели по эталону |

Журнал циклов разработки — [`journal/`](journal/README.md).
