# Журнал циклов разработки

Цикл разработки — анализ данных → доработка решения или проверка гипотезы → верификация
(прогон в симуляторе) → фиксация результата цифровыми данными, которые служат основой
следующего цикла. Каждый цикл — запись ниже и каталог `journal/cN/` с исходными данными
(`scenario.json`), итоговыми показателями (`summary.json`) и временным рядом (`series.csv`).
Версия — тег и коммит репозитория.

Показатели ФТ № 1 (Р1.7) и их обозначения в `summary.json`:

| Показатель | Требование | Поле |
|---|---|---|
| Квант обработки и выдачи обновлённого состояния, 8 БВС | ≤ 0,5 с | `quantum_s.max` |
| Восстановление согласованности после разрыва связи | ≤ 1,5 с | `restores[].store_conv_s` |
| Работа при разрывах связи | до 15 мин | разделение `scenario.net.partition` |
| Сходимость к одинаковому состоянию (Р1.4) | одинаковые картины | `settle_conv_s`, `final_pictures_identical` |
| Потери данных при синхронизации (Р1.3, Р1.5) | минимизируются | `records_missing_per_uav` |
| Логические дубликаты (Р1.3) | минимизируются | `picture.duplicates` |

## Цикл 0 — 18.11.2026, версия 0.0.1

**Анализ.** Требования ФТ № 1 (Р1.1–Р1.8) сопоставлены с заделом команды (СПО демонстратора
СЦ, НИОКР «Центр»): взяты подходы — ковариационное пересечение при слиянии оценок,
дедупликация треков по расстоянию Махаланобиса с запретом «один источник в одном кадре»,
досылка недостающего по порядковым номерам, модели датчика и канала. Выявлено главное
отличие задачи: картина должна согласовываться между бортами без наземного центра, и
копии должны сходиться независимо от порядка сообщений — в заделе обработка зависит от
порядка (жадная ассоциация, случайные идентификаторы).

**Доработка (новое решение, с нуля).**
* реплицируемое хранилище — CRDT «регистры с единственным писателем», векторы версий,
  дельта-синхронизация с проверкой полноты диапазона (`store.py`);
* общая картина — детерминированная функция содержимого хранилища: ассоциация в
  каноническом порядке, CI, идентификаторы по хешу (`fusion.py`);
* анти-энтропия с вытягиванием недостающего по каждому источнику у одного соседа (`node.py`);
* модели мира (рой 8 БВС в строю 12 × 4 м, маршрут 30 км), датчика, навигации без ГНСС,
  сети с разделением на подгруппы, потерями, полосой (`world.py`, `sensors.py`, `net.py`);
* показатели по эталону и проверка сходимости (`sim.py`); 11 автотестов свойств CRDT,
  детерминизма картины и сквозного прогона.

**Исходные данные.** `scenarios/base.toml`, seed 7: 8 БВС, 100 км/ч, 60 объектов интереса;
сеть 500 кбит/с, задержка 30 ± 10 мс, потери 5 %; **разделение роя на две изолированные
подгруппы на 15 мин** (60–960 с), отказ U06 во время разрыва (400 с), присоединение U09 (1000 с).

**Результат.**

| Показатель | Требование | Цикл 0 |
|---|---|---|
| Квант обработки, наибольший | ≤ 0,5 с | **0,4 с** (95 % — 0,2 с) |
| Затраты на пересчёт картины, 95 % | — | 5,4 мс |
| Восстановление после разрыва 15 мин | ≤ 1,5 с | **1,4 с** |
| Получение состояния присоединившимся U09 | ≤ 1,5 с | 1,9 с — **не выполнено** |
| Сходимость после остановки записи | одинаковые картины | 1,1 с, картины 8 бортов совпали |
| Потери записей | 0 | 0 |
| Объекты картины / объекты эталона | — | 60 / 42 |
| Логические дубликаты | min | **15 (36 %)** |
| Ложные объекты | min | 3 |

**Выводы и задачи следующего цикла.**
1. Восстановление на грани (1,4 с), присоединение не укладывается (1,9 с). Прогоны с
   потерями 0 % дают 0,5–0,7 с — время уходит на фиксированный тайм-аут повторного
   запроса (0,6 с) после потери сообщения. Цикл 1: адаптивный тайм-аут по RTT, запрос
   у двух соседей при восстановлении, передача снимка новичку по частям.
2. Дубликаты 36 %: треки одного объекта с разных бортов не объединяются из-за смещения
   навигации (у каждого борта своё) и жадного порядка ассоциации. Цикл 2–3: оценка и
   компенсация взаимного смещения бортов по общим объектам; модель сходства наблюдений
   на основе ИИ, обучаемая на эталоне.
3. Служебный трафик — 255 тыс. сообщений за прогон, в основном векторы версий.
   Перейти на широковещательную передачу (mesh-радиосеть — общая среда).
