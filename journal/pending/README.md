# Серии без номера цикла

Прогоны, сделанные после записи цикла 2 на коде ветки `feat/core`; номер цикла
назначает координация (регламент п. 5), после этого серии переносятся в `journal/cN/`.

- `v200_4x4` — `scenarios/v200_4x4.toml`, seed 1–5: 200 км/ч, маршрут 30 км (9 мин),
  разрыв 4 + 4 на 15 мин, отказ U06, присоединение U09.
- `v200_isolated` — `scenarios/v200_isolated.toml`, seed 1–5: 200 км/ч, каждый борт
  изолирован 15 мин.

Код прогонов: коммит с этим файлом (метрики задержки фиксации и объёма хранилища,
исправленный отсчёт присоединения).
