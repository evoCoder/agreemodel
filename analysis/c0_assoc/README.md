# Разбор дубликатов картины цикла 0

`python tools/diag_assoc.py scenarios/base.toml --seeds 1-10 --out runs/diag_c0` (версия 0.0.1, коммит c0d83eb).
Файлы: `summary.json` — итоги по 10 seed, `events.jsonl` — каждый пропущенный случай слияния.

| Показатель (10 seed) | Значение |
|---|---|
| Объектов эталона в картине | 462 |
| Дубликатов | 175 (37,9 %), по seed от 13 до 23 |
| Пропущенных слияний, разобрано | 174 |
| из них: запрет «два трека одного борта одновременно» | **174 (100 %)** |
| смещение навигации, порог, классы, устаревание, индекс | 0 |

Расстояние Махаланобиса в пропущенных слияниях — 0,02–3,1 при пороге 16: по положению
треки объединились бы. Слияние запрещает правило `fusion.py`: у борта-источника два
трека одного объекта с пересекающимися интервалами наблюдения.

Причина — локальное сопровождение (`node.py`): обнаружение, не попавшее в строб трека
(χ² = 13,8, по построению около 0,1 % истинных обнаружений; на 300 с — 5 из 4529),
открывает новый трек; GNN дальше делит обнаружения между двумя треками, второй набирает
3 отметки и публикуется. Пример (seed 7, U04, объект T011): trk/3 — 32,4–49,8 с, 39 отметок;
trk/7 — 48,4–49,6 с, 3 отметки; промах строба при d² = 16,4 (невязка 20 м при σ = 5 м).

Гипотеза цикла 0 («дубликаты из-за смещения навигации») не подтвердилась: ковариация
публикуемого трека включает дисперсию навигации, её хватает. Попутно: ошибка навигации
`Sensor.nav` в прогоне не обновляется (`GaussMarkov2D.step` не вызывается) — смещение
каждого борта постоянно весь прогон.
