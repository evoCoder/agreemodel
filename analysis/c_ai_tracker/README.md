# Исправление раздвоения треков в локальном сопровождении

Продолжение разбора `analysis/c0_assoc/` (там: 175 дубликатов из 462, все — раздвоение
трека одного борта). Изменения (`node.py`, `sensors.py`, `config.py`):

1. **Приоритет подтверждённых треков** при распределении обнаружений (GNN): новый трек с
   большой ковариацией, открытый часто ложным обнаружением рядом с объектом, больше не
   перехватывает отметки объекта.
2. **Второй этап ассоциации:** обнаружение вне строба (χ² 13,8), но с d² ≤ `node.gate2_d2`
   = 40 до подтверждённого трека, не получившего отметки в этом кадре, отдаётся этому
   треку, а не открывает новый. Основание: датчик даёт не больше одного обнаружения объекта
   за кадр. `node.gate2_d2 = 0` — поведение цикла 0.
3. **Ошибка навигации меняется во времени** (гаусс-марковский процесс, σ = 4 м, τ = 60 с):
   в цикле 0 `GaussMarkov2D.step` не вызывался, смещение было постоянным.
   `nav.drift = false` — поведение цикла 0.
