одного борта). Ветка `feat/ai` объединена с `feat/core` (цикл 2 в работе, чат 1), где уже

открыт ложным обнаружением рядом с объектом) выигрывает распределение по d² и
перехватывает отметки объекта. Добавлено: **подтверждённые треки получают обнаружения
первыми** (`node.confirmed_first`, по умолчанию true; false — как в циклах 0–1).
